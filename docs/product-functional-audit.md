## Достоверность

MICCEDU — редакция 2025, опубликованное обновление 03.02.2026. Проверка
официального индекса и карточки СГУ выполнена 2026-11-08:
[индекс](https://monitoring.miccedu.ru/?m=vpo&year=2025),
[карточка 258](https://monitoring.miccedu.ru/iam/2025/_vpo/inst.php?id=258).
Это участники мониторинга с исключениями, не полный актуальный реестр вузов.
Artifact сохраняет исходные даты захвата; повторное открытие индекса не
делает все 1257 записей проверенными сегодня.

Для программ переиспользуются ранее независимо сверенные metadata:
[SGU 4588](sources/sgu-4588.md), [SGU 4576](sources/sgu-4576.md),
профили `sources/profiles` и aggregate audit reports. Подтверждены 16 и 24
общих бюджетных места в архиве 2026, код, название, форма и конкурс.
Текущий web-доступ к двум страницам СГУ не сработал; данные **архивные**,
не обозначаются свежей кампанией 2027. Ни candidate fixture, ни баллы
последнего кандидата не используются как исторический проходной.

## План и карта API первого среза

1. Новый публичный read facade внутри текущего FastAPI. Старые routes без
   изменений. Нет записи через HTTP, создания гостевой сессии и доступа к PII.
2. Явная идемпотентная CLI-загрузка двух reviewed metadata в существующие
   University/Campaign/CompetitionGroup. Без миграции, новой БД, Source rows
   и включения worker. Несовпадение существующей записи — отказ, не overwrite.
3. `GET /api/v1/catalog/universities?q=&region=&offset=&limit=&sort=`:
   справочник, facets регионов, bounded страницы и ссылки/даты редакции.
4. `GET /api/v1/catalog/universities/{id}`: организация, годы доступных
   конкурсов, confirmed program count и provenance. Неизвестный ID → 404.
5. `GET /api/v1/catalog/programs?q=&universityId=&year=&subject=&offset=&limit=&sort=`:
   только imported metadata, совпадающие с reviewed scope; total/nextOffset,
   years/subjects. Unknown exam requirements не проходят subject filter.
6. `GET /api/v1/catalog/programs/{id}`: campaign-scoped ID, funding/form,
   seats, code и provenance, cutoff/exams/forecast null. 0 мест отличается от null.
7. React: отдельные `catalog/api`, DTO/state hook, cards и pages. Четыре
   старые композиции подключаются к ним; CSS/components остальных страниц
   не переписываются. Вуз/программа — динамические стабильные ID в URL.
   Ошибка не заменяется demo; stale ответ отменяется/игнорируется, есть retry.
8. Регион используется вместо неподтверждённого города. Новый year selector
   нужен для реального выбора кампании; несуществующий год даёт empty, а не
   подстановку другой кампании. В исходном UI нет сортировки/пагинатора:
   добавить компактные controls существующего вида для реального объёма.
9. Реальные карточки не ведут к demo forecast и demo watchlist. Сохранение и
   сравнение реальных ID — отдельный следующий срез. Демо-страницы остаются,
   но не являются результатом модели. На реальной detail прогноз — «Нет данных».
10. Backend/API positive/negative tests, install/typecheck/ESLint/build,
    desktop/mobile journey/error/empty/stale tests; source CSS неизменен;
    pixel comparison незатронутых страниц и скриншоты четырёх реальных страниц.

Критичные пробелы: свежие кампании/полный перечень программ, исторические
проходные по сопоставимым конкурсам, официальные требования ЕГЭ и city dataset.
Они не блокируют честный архивный каталог, но блокируют прогноз и полноту.
ML и внедрение остальных 25 страниц в этом подходе не выполняются.
