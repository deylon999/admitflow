# Каталог MVP

Начальный набор: **2 исследованных вуза**, СГУ (Саратов) и СГУПС (Новосибирск), без филиалов. Это не каталог всей России и не две готовые автоматические интеграции.

Каждая запись имеет стабильный внутренний ID, официальный URL, provenance URL и дату проверки 2026-11-01. Источники описаны в [аудите](evidence/source-audit.md). Оба coverage = manual. Программы/группы не создаются по догадке из названия вуза.

GET /api/v1/universities?q= возвращает items/total, максимум 50 результатов. Поиск по имени/ID одинаково обрабатывает кириллицу в SQLite и PostgreSQL. При росте каталога заменить первоначальную фильтрацию на индексируемый поиск с пагинацией.

Seed добавляет отсутствующие записи и сохраняет существующие правки. Начальная миграция создаёт структуру; application startup добавляет этот набор. Расширение требует provenance и разделения головного вуза/филиала. Подключение автоматического режима — отдельная аттестация источника и правил.

## B12: воспроизводимый отчёт двух архивов

Начальный seed выше содержит2вуза. Явная регистрация проверенного GUAP добавляет третий вуз каталога;это отдельное действие,а не доказательство автоматизации всех трёх. На локальном проверенном контуре загружены2независимых архива:СГУ573строки/общий бюджет16мест иГУАП581строка/платный конкурс0мест/неизвестные согласия. Это1154строки текущих снимков,не1154уникальных человека. Условная числовая модель доступна только для бюджетной группы СГУ;она не вычисляет официальный результат. Архивы не увеличивают показатель свежих текущих групп.

GET `/api/v1/coverage` воспроизводится поSource/PublishedSnapshot/Campaign/CompetitionGroup и точным scope-паспортам runtime registry:

- catalogUniversities — все записи справочника;registeredSources — все зарегистрированныеSource,включая отключённые/непроверенные.
- reviewedSources — включённыеSource,чьи URL/year/kind/parser разрешены отдельной аттестацией. Две версии доказательства одногоscope не считаются двумя источниками.
- importedSources/importedGroups/importedUniversities — включённые проверенныеSource с полным опубликованным снимком,normalized hash и совпадающей версией parser;группы/вузы дедуплицированы. Регистрация без снимка ничего не прибавляет.
- importedRows — сумма строк текущих опубликованных снимков,не количество людей. archiveImportedGroups — группы,все опубликованные источники которых архивные. Карантин сохраняет эти датированные последние исправные архивы;это не успешная новая проверка.
- conditionalGroups — подмножество импортированных общих бюджетных групп с listed-consent-v1 и явным положительным числом мест. Платный GUAP сюда не входит.
- automaticSources/publishedGroups/freshGroups/archiveGroups — прежние отдельные показатели явно принятого автоматического режима coverage=automatic и правил. Разрешение условной архивной модели не включает этот режим.
- lastImportedAt — максимальная исходная fetchedAt опубликованного снимка;повторный запрос/проверка/seen не изменяют её. generatedAt — время формирования отчёта.

NationalTotal остаётсяnull:проверенного национального знаменателя нет,процент охватаРоссии не рассчитывается. Отключение/потеря аттестации/незавершённый снимок исключают scope из импортного показателя;данные вБД не удаляются. API не выдаёт сведения о владельцах/кандидатах.
