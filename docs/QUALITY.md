# Качество и критерии приёмки

Уточнение S201: общая DoD, data/privacy/worker инварианты ниже сохраняются.
Пункты ручного UI и старые MVP-gates — исторические, не требования вернуть
калькулятор в v3. Актуальные проверки UI/API и platform limits записаны в
[foundation-cleanup](evidence/foundation-cleanup.md). Native PostgreSQL не
считается проверенным по SQLite; отсутствие Docker — отдельный блокер.

Все численные пороги ниже — проектные цели, не результаты текущего измерения. Изменение порога требует записи причины до повторного теста.

## Definition of Done для задачи

1. Выполнены шаги и acceptance карточки; публичный контракт документирован.
2. Проверка относится к текущему исходному коду и версии схемы, а не к старой сборке.
3. Проверены успешный сценарий, существенная граница и ожидаемый отказ.
4. Нет секретов/чужих идентификаторов в логе и тестовых артефактах.
5. Сохранены команды, exit codes, дата, ограничения и файлы доказательств.
6. TASKS/STATE/LOG согласованы, документация не обещает отсутствующую функцию.
7. Изменение можно воспроизвести из checkout и закреплённых зависимостей; необратимые миграции имеют проверенный план восстановления.

Для задачи исследования доказательство — датированный источник, вывод и явно перечисленные неизвестные. Для deployment — фактическая версия и проверенный URL; ожидаемый URL не является доказательством.

## Обязательные доменные случаи

- Люди вне того же конкурса уже отсутствуют в выгрузке: не вычитать повторно.
- Один человек помечен двумя причинами: не вычитать дважды.
- Приход согласия меняет сценарий, но не переписывает прошлый снимок.
- Отозванная заявка и отсутствие согласия — разные состояния.
- Совпадающий публичный ID в разных вузах/сезонах не объединяет людей.
- Приоритет не известен: не вычислять официальный результат на основании догадки.
- Ошибочное число мест: отказ/карантин, а не красивый положительный статус.
- Последний запрос упал: последнее корректное значение сохраняется с меткой устаревания.
- Источник прислал неполную пагинацию: latest не переключается.
- Архив воспроизводится с видимой датой архива.
- Повтор POST после потери ответа не создаёт дубли при предусмотренной идемпотентности.
- Одновременные запросы не обходят лимиты 20 направлений/500 ручных снимков, если эти лимиты сохранены в продукте.

## Критерии выпуска

- G0–G5 пройдены с проверяемыми доказательствами.
- Два официальных источника имеют паспорта и аттестованные адаптеры. Минимум 50 записей на источник сверены по существенным полям; при меньшем списке — все. Граница бюджета и спорные случаи включены обязательно.
- Автоматическое обновление проверено в течение 24 часов наблюдения на доступном источнике. Дополнительно контролируемый replay демонстрирует реальные изменения; отсутствие изменений живого списка само по себе не тестирует diff.
- Нет нерешённых критических ошибок доступа, расчёта, потери данных или ложного статуса свежести.
- Главные пользовательские пути проходят в Chromium, Firefox, WebKit либо ограничения платформы явно отражены и не заявлена неподтверждённая совместимость.
- Production smoke выполнен после выпуска, а не только на localhost.
- Backup восстановлен в отдельное окружение; данные и ownership совпадают с контрольным набором.
- Приёмка показывает фактические границы покрытия и модели. Никаких неподтверждённых процентов вероятности.

## Классы дефектов

**P0:** чужие данные, неверное решение о положении из-за ошибки, утрата данных, недоступность основного пути. Блокирует релиз.

**P1:** существенная проблема пути, stale/история/источник отображаются неверно, адаптер нестабилен. Блокирует затронутую функцию; допустимо отключить функцию явно с сохранением MVP-gates.

**P2:** косметика/удобство без искажения данных. Исправляется по оставшемуся времени, фиксируется в известных ограничениях.

Отключение одного из двух обязательных источников не превращает gate автоматизации в пройденный.
