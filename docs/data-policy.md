# Политика данных для MVP

Инженерные ограничения, принятые 2026-11-01. Они не подтверждают юридическую готовность внешнего сервиса. Перед внешним запуском владелец проекта определяет оператора, площадку размещения и основания обработки/повторного использования каждого источника.

- В ручном режиме нужны только вуз, направление, официальный URL и четыре числа. Не запрашивать ФИО, паспорт, СНИЛС, документы или контакты.
- Публичный код кандидата ограничен вузом/филиалом/сезоном. Не объединять человека между вузами и не строить глобальный профиль.
- Гостевые данные принадлежат одной сессии браузера. Cookie HttpOnly/SameSite=Lax, срок 30 дней без автоматического продления. После истечения объяснить потерю доступа; не заменять сохранения новой пустой сессией молча.
- Несохранённая форма временно хранится в sessionStorage текущей вкладки: одна запись до16KiB, поля формы и ключ безопасного повтора, без cookie и owner hash. Scope односторонне отделяет гостевые сессии и не служит авторизацией. Доступность — до30 минут с последнего изменения/явного восстановления, не дольше гостевого срока; чтение не продлевает TTL. Просроченная запись удаляется при чтении или срабатывании таймера. Очистка при401, reset, смене доступа в другой вкладке, успешном сохранении и явном отказе. Это обычное локальное хранилище браузера, не зашифрованный backup и не гарантия восстановления после закрытия/сбоя. При запрете storage показывается предупреждение, форма продолжает работать.
- Должно быть доступно явное удаление всей гостевой сессии и её направлений/истории. Просроченные сессии очищать не позднее суток после истечения. Резервные копии живут не более 14 суток; удаление из backup наступает по сроку ротации.
- Исходные ответы хранить приватно и не выдавать через публичный API. В development TTL7суток применяется к orphan raw без ссылок;raw,нужные неизменяемой истории,сохраняются до отдельного согласованного campaign purge. Production срок/ротация referenced raw остаётся открытым требованием T049 и блокирует публичный запуск. Default response cap5MiB,только trusted adapter может объявить<=8MiB. Не логировать тела/коды кандидатов.
- В Git только синтетические либо обезличенные образцы с provenance. Сохранённый через веб-просмотр текст не выдавать за оригинальный HTML. В логах — ID операции, домен источника, код результата и длительность, без cookies, секретов и query-параметров.
- Загружать только зарегистрированные домены. Не обходить CAPTCHA, авторизацию, 403 или ограничения частоты. Доступность страницы не является разрешением на массовое копирование.

Открытые вопросы до выпуска: условия каждого источника, правовое основание и уведомление пользователя, ответственная сторона, размещение данных, фактическая ротация raw/backup, процедура запросов на удаление. Ответственный за закрытие — владелец проекта. Любой незакрытый обязательный вопрос остаётся в релизной приёмке.
