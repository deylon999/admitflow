# Документация проекта

Начать с [ROADMAP.md](ROADMAP.md), продолжать работу по [STATE.md](STATE.md).

| Файл | Назначение | Когда обновлять |
| --- | --- | --- |
| [PRODUCT.md](PRODUCT.md) | Пользователь, сценарии, состав MVP и пределы обещаний | При изменении требований |
| [ROADMAP.md](ROADMAP.md) | 30 дней, этапы, контрольные точки, правила сокращения объёма | При пересмотре сроков |
| [TASKS.json](TASKS.json) | Единственный реестр задач, зависимостей, статусов и доказательств | При каждом переходе задачи |
| [TASKS.md](TASKS.md) | Читаемые карточки всех задач; генерируется | Командой `--render` |
| [STATE.json](STATE.json) | Текущая задача, следующий шаг и выполненные контрольные точки | Перед остановкой работы |
| [STATE.md](STATE.md) | Краткая передача контекста следующей сессии | Перед остановкой работы |
| [LOG.md](LOG.md) | Неизменяемая история действий и результатов | После законченного блока работы |
| [DECISIONS.md](DECISIONS.md) | Обоснования выбора технологий и продуктовых решений | При новом решении |
| [ARCHITECTURE.md](ARCHITECTURE.md) | Модули, данные, API и развёртывание | При изменении контрактов |
| [DATA_RULES.md](DATA_RULES.md) | Правила расчёта, импорт, свежесть, источники и ИИ | До изменения расчётов |
| [QUALITY.md](QUALITY.md) | Критерии приёмки, тесты и разрешение релиза | При уточнении требований |
| [RISKS.md](RISKS.md) | Риски, неизвестные и действия при проблемах | При появлении новых фактов |
| [RUNBOOK.md](RUNBOOK.md) | Возобновление, запуск, проверка, выпуск и восстановление | После изменения команд |

План — спецификация будущей работы. Реализованное и проверенное отмечено отдельно в STATE и TASKS. Примеры конечных API и схемы данных не означают, что они уже существуют.
