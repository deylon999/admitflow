# Еженедельный отчёт

Отчёт за неделю (понедельник–воскресенье) публикуется в `docs/reports/<год>-W<неделя>.md`, черновик собирается скриптом:

```
python scripts/weekly_report.py --week 2026-W46 --output docs/reports/2026-W46.md
```

Скрипт берёт факты из git и `docs/TASKS.json`. Срок, риски и пропущенные связи дописывает ответственный.

## Разделы

| Раздел | Что сюда попадает |
| --- | --- |
| Сделано | Изменение прошло review и слито в main. Только так задача получает Done. |
| На проверке | Код в открытом PR с зелёным CI, карточка в In Review. |
| В работе | Задача начата или запланирована на неделю. |
| Заблокировано | Задача стоит. Указаны причина и кто или что её снимет. |
| Риски и решения | Что нужно решить команде или владельцу продукта. |

## Колонки

| Колонка | Правило |
| --- | --- |
| Задача | Ключ Jira (KAN-…) или номер из TASKS.json. |
| Что | Результат одной строкой: что теперь работает, а не чем занимались. |
| Статус | Done, In Review, В работе, Blocked. |
| Срок | Дата, о которой договорились. Если срока нет, поле пустое: дату не придумываем. |
| Доказательства | Коммит, PR, отчёт из `docs/evidence/`, скриншот или прогон CI. Без доказательства пункт не считается сделанным. |
| Ответственный | Кто делает и отвечает за результат. |

## Definition of Done

1. Результат реализован.
2. Есть проверка: тест, прогон или ручная проверка, описанная в evidence.
3. Есть ссылка на коммит или артефакт.
4. Прошло review.
5. Только после этого Done.
