# Технический пилот

Сезон исследования: **2026**. Это выбор для разработки и архивного воспроизведения, не обещание живых списков. Оба источника пока кандидаты.

## СГУ

- Индекс: https://www.sgu.ru/svodka
- Наблюдаемый пример таблицы: https://www.sgu.ru/svodka/4155 — магистратура, исключена из стартового охвата.
- Стартовый кандидат бакалавриата: https://www.sgu.ru/svodka/4588 — получение пока timeout, параметры группы не аттестованы.
- Разные группы мест нельзя объединять; число общих мест берётся из конкретной группы.
- Таблица содержит официальный порядок, публичный код, баллы, согласие, статус и приоритеты. Баллы не заменяют порядок строк.
- Правила: https://www.sgu.ru/sites/default/files/page/files/pravila-priema-2026_0.pdf, разделы VII–VIII, пункты 82–90. Приоритеты и согласие участвуют в зачислении; упрощённое вычитание не воспроизводит официальный итог.
- Неизвестны: актуальность идентификаторов URL между сезонами, полнота ответа, условия повторного использования, разрешённая частота. До проверки — без автоматического fetch в production.

## СГУПС

- Индекс: https://www.stu.ru/abiturient/spiski_abiturientov/konkursnie_spiski
- Категория: https://www.stu.ru/abiturient/abiturients_table_show.php?type=konkursnie_spiski_obshii_bud
- Индекс разделяет финансирование и профили. Это отдельный формат от СГУ.
- Не аттестованы: исходный HTML конкретного профиля, дата/число мест/колонки, правила приоритетов, сезонные URL, условия использования.
- До аттестации разрешены переход к официальному сайту и ручной режим; автоматический прогноз не включать.

Следующая проверка каждого паспорта: оригинальный ответ + hash + версия адаптера + сверка контрольных строк. Не хранить здесь реальные коды поступающих.

## Получение оригинальных ответов

Из backend: `.venv/Scripts/python.exe -m app.sources.capture fetch sgu-2026-4588` или `fetch sgups-2026-1348`. Закрытые цели: указанный СГУ 4588 и профиль СГУПС 09.03.02, specializ=1348, обнаруженный в официальном индексе. URL профиля не подтверждает его содержимое/места/полноту. Произвольный URL не принимается. Команда сохраняет original bytes и manifest/hash в приватный backend/var/captures; `python -m app.sources.capture verify ПАПКА` перепроверяет bundle. Не добавлять реальные raw с публичными ID в Git; для тестов нужны отдельно обезличенные образцы.

Capture только подготавливает material для исследования; attested=false, archive/2026, никакого enable worker/изменения coverage. Успешный capture сам по себе не аттестует адаптер.
