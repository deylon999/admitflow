## Получение оригинальных ответов

Из backend: `.venv/Scripts/python.exe -m app.sources.capture fetch sgu-2026-4588` или `fetch sgups-2026-1348`. Закрытые цели: указанный СГУ 4588 и профиль СГУПС 09.03.02, specializ=1348, обнаруженный в официальном индексе. URL профиля не подтверждает его содержимое/места/полноту. Произвольный URL не принимается. Команда сохраняет original bytes и manifest/hash в приватный backend/var/captures; `python -m app.sources.capture verify ПАПКА` перепроверяет bundle. Не добавлять реальные raw с публичными ID в Git; для тестов нужны отдельно обезличенные образцы.

Проверка B03 2026-11-01: исходящий capture СГУ завершился network_error / captured=false / exit 1; успешного оригинала нет. Повторное чтение web-инструментом: СГУ 4588 timeout, профиль СГУПС 1348 cache miss. В текст индекса не восстанавливать придуманные HTML-теги. Capture только подготавливает material для исследования; attested=false, archive/2026, никакого enable worker/изменения coverage. Успешный capture сам по себе не аттестует адаптер.
