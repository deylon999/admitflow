## СГУ

- Индекс: https://www.sgu.ru/svodka
- Наблюдаемый пример таблицы: https://www.sgu.ru/svodka/4155 — магистратура, исключена из стартового охвата.
- Стартовый кандидат бакалавриата: https://www.sgu.ru/svodka/4588 — получение пока timeout, параметры группы не аттестованы.
- Разные группы мест нельзя объединять; число общих мест берётся из конкретной группы.
- Таблица содержит официальный порядок, публичный код, баллы, согласие, статус и приоритеты. Баллы не заменяют порядок строк.
- Правила: https://www.sgu.ru/sites/default/files/page/files/pravila-priema-2026_0.pdf, разделы VII–VIII, пункты 82–90. Приоритеты и согласие участвуют в зачислении; упрощённое вычитание не воспроизводит официальный итог.
- Неизвестны: актуальность идентификаторов URL между сезонами, полнота ответа, условия повторного использования, разрешённая частота. До проверки — без автоматического fetch в production.
