# Первые документы каталога программ — KAN-218 PR2

Это перечень захватов, не статус публикации или полное покрытие вузов.
Исходные HTML содержат сторонние блоки страницы и контакты; они остаются
в private research cache вне Git. В репозитории — хеши, reviewed факты и
минимальные очищенные fixtures. Записи абитуриентов не загружались.

Воспроизведение одного источника из корня (4 сетевых запроса для обоих вузов:
robots + один документ на каждый, последовательно, без автоматических retries):

```text
backend/.venv/Scripts/python.exe scripts/capture_program_catalog.py hse-design-2027
backend/.venv/Scripts/python.exe scripts/capture_program_catalog.py sgu-seats-2026
```

Существующий pinned HTTPS fetcher проверяет домен/DNS/TLS/redirect/MIME/размер/
таймаут. Robots читается до документа; disallow или ошибка не обходятся.
Минимальная пауза2s; более строгий crawl-delay соблюдается, >60s требует
отдельного операторского запуска. Captured не означает reviewed/published.
Новый документ не перезаписывает старый: файлы именуются по SHA256.

| Источник | Подтверждаемая область | Ограничение |
| --- | --- | --- |
| https://design.hse.ru/ba/join | Вводный абзац2027, три московские программы, бакалавриат; официальные ссылки задают source keys | На странице также есть2026: их места/ЕГЭ/условия в2027 не переносить. Код и условия пока неизвестны |
| https://www.sgu.ru/node/240763 | Меню «Приём2026» с этой ссылкой; отдельная таблица головного вуза/бакалавриата/очной формы, строки программ | Бюджет total и платные места не являются автоматически местами общего конкурса; профильные подпункты не разделять на фиктивные конкурсы |

Оба robots разрешили точные пути для фактического User-Agent AdmitFlow/0.2.
Это основание ограниченного технического чтения публичных неперсональных
сведений; массовый сбор/внешний выпуск требует принятия оставшихся source-use
условий из data-policy. Даты UTC исходных захватов сохранены буквально:
2026-11-20T21:31Z соответствует21ноября по Москве.

План РЭУ в PDF найден, но в этот захват не включён: текущий fetcher не допускает
PDF MIME. Не выдавать поисковый текст за оригинальный PDF. PDF-семейство пока
не подключено. Для первого набора выбраны два независимо проверяемых HTML
источника; приёмка нескольких форматов остаётся в дальнейшем расширении.
