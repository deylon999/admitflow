# Архив очистки фундамента

[Отчёт S201](../foundation-cleanup.md), [browser summary](browser-results.json)
и [JUnit](portable-backend.xml) фиксируют отдельный прогон. В подпапках
[каталожного среза](../catalog-vertical-slice/gallery.html) сохранены 20 PNG,
побайтово совпадающих с прежними кадрами этого прогона с теми же путями
`<width>/<page>.png`. Обе стороны пары `unchanged/landing-*.png` доступны
через [единый PNG](../catalog-vertical-slice/unchanged/landing-original.png).

[Первоначальное дерево отчёта и скриншотов](https://github.com/deylon999/admitflow/tree/662b746f3383bfbeaac54aeeba61669f85851cd5/docs/evidence/foundation-cleanup).
