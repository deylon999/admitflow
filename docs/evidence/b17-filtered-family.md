# B17/T206 — общий filtered decoder

2026-11-05. `reviewed-filtered-table-v1` расширяет прежний общий decoder,
а не добавляет отдельный алгоритм БГУ. Профиль задаёт exact identity выбранных
контролов/плана/формы, source count, spans заголовков, классы/публичную программу
ячеек, extraction минимального кода и строгий enrollment marker.

Дополнительные настройки разрешены только новой версией. Старые версии,
профили и hashes не изменены. Персональные части составного кода отбрасываются
до HMAC; разные полные коды с одним первым сегментом считаются дублированием
и отклоняются. Отсутствие marker означает unknown, не отказ/отзыв. Оплата и
вспомогательные номера не стали согласием/приоритетом.

Новый fixture построен только из публичной структуры: все109кодов, баллы,
даты/приказы и статусы кандидатов в нём синтетические. Prepare profile всё ещё
proof=null и не опубликован в runtime registry; аттестация — следующий шаг.

Проверки на Linux с обязательным native PG:65passed/0skipped(15.99s), включая
старые V1/V2/section и manifests. Новый набор проверяет другой/дублированный
selected option, частичный checkbox, план/count, изменённые роли TD/программу,
одинаковый минимальный код при разных остальных частях, неизвестный статус,
spans, сезон, пагинацию, обрезку. Изменение отбрасываемых частей кода не меняет
нормализованную запись. DATA_RULES/ADR-032 обновлены вместе с кодом/тестами.
