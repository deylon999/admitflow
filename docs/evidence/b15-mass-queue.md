# B15/T199 — очередь и фактическое покрытие

2026-11-05. Native PostgreSQL, отдельные disposable schemas, реальные источники
не заменены нагрузочными фикстурами.

`b15-mass-queue.json`: 1000 синтетических заданий на 100 доменах, 12 потоков
захвата, десять волн завершения. В каждой волне не более одного активного
задания на домен. Все 1000 завершены однократно; 24 конкурентных enqueue
создали одно задание. Восстановлены 100 просроченных leases; все старые
renew/complete отклонены. Тест не измеряет сетевую пропускную способность
и не добавляет реального покрытия. SKIP LOCKED может вернуть idle, пока
другой claimant держит пакет кандидатов; после снятия блокировок работа
продолжается, это не доказательство пустой очереди.

Worker loop получил process-local `PageFetchCache`: до 64 страниц/32 MiB,
повторное использование менее 60 секунд, отдельный ключ URL/domain/allowlist/
max_bytes. Ограничения транспорта проверяются и на cache hit. Ошибки, неверный
hash, слишком большой ответ, изменившийся redirect URL и старые/будущие даты
не кэшируются. FetchedAt и исходные bytes/hash сохраняются, поэтому cache hit
не обновляет дату снимка. Истёкшие записи удаляются при следующем обращении;
это ограничение повторного использования, не обещание таймера удаления памяти.
Кэш отдельный у каждого процесса; распределённой дедупликации между worker
нет. Domain leases по-прежнему находятся в PostgreSQL.

`b15-coverage-runtime.json`: действительные HTTPS загрузки **13 URL для 14
scopes**, 1 cache hit; все worker-публикации и 14 offline stored audits успешны.
Получены 1775 строк четырёх вузов; 168 новых строк повторно независимо сверены
со stdlib parser на текущих оригиналах. Для старых групп сохранены прежние
профили/версии/доказательства. Схема удалена; пользовательская БД не менялась.

Итог этого запуска: каталог1257, зарегистрировано/проверено/импортировано14
групп, 4 вуза, 14 архивных групп, 2 условных бюджетных сценария, 0 свежих групп,
0 automatic eligibility, nationalTotal=null. Строки не являются уникальными
людьми. Неизвестные/недоступные страницы из инвентаризаций не стали supported.

Отдельный локальный Compose `admitflow-b15-demo` содержит эти 14 реальных
архивов и worker, с постоянными отдельными volumes и ключом в ignored
`backend/var/b15-demo.env`. Сайт слушает только 127.0.0.1:8091; PostgreSQL не
опубликован. Старые пользовательские БД/volumes не использованы. Повторный
импорт архивов назначен раз в сутки, он не делает архив fresh. Ключ сохранять
вместе с этой средой, не регенерировать для исправления ошибок.

Первый одноразовый helper запуска демо не имел multiprocessing main guard:
spawn повторно вошёл в helper, задания не опубликовались. Guard исправлен;
только собственные ошибочные задания нового демо возвращены в очередь,
после чего все14 опубликованы. Этот helper не входит в приложение или Git.

Финальные проверки и ограничения браузерного прогона приведены в
`b15-final-verification.json`. T056/T057 остаются открытыми.
