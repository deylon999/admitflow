# T236 — финальная проверка UI/UX

Acceptance до реализации (2026-11-07, S193): проверить production frontend в
реальном браузере на375/768/1280/1920px, обе темы, страницы/карточки/формы,
loading/empty/error, клавиатуру и видимость focus. Просмотреть реальные снимки,
проверить CSS-конфликты и регрессии общих компонентов; исправлять только
подтверждённые проблемы без редизайна/изменения бизнес-правил. Выполнить
typecheck/lint/build и необходимые тесты. Сохранить ограничения, остаточные
проблемы и фактический git diff --shortstat. Без временных диагностических
скриптов в служебных каталогах, без commits/push. Прежние локальные T233–T235
сохраняются; diff относится ко всему рабочему дереву и не включает untracked.

## Результат

Production-сборка запущена через Vite preview на 127.0.0.1:5285. Фактически
запущен Chromium; проверены 375, 768, 1280 и 1920 px в light/dark. Просмотрены
реальные PNG, включая полную главную, калькулятор, каталог, tracker, создание
и редактирование направления, ошибку и пустой список. Нового редизайна нет.

Подтверждённый дефект: заголовок «Как получен результат» имел область нажатия
22.39 px высотой. Общее правило summary теперь использует системные 44 px;
повторное измерение production DOM показало 44 px при 375 и 1280 px.
Удалены перекрываемые правила 40/46 px для темы и CTA, дубли управления
видимостью мобильного меню, cursor:wait и локальные повторы размера summary.
Кнопки используют существующие примитивы и токены. Бизнес-правила, backend,
API и FSD не менялись; прежние локальные T233–T235 сохранены.

В проверенных сценариях нет горизонтального скролла страницы, выхода
контейнеров и элементов управления за viewport, текста меньше 12 px,
заголовков сверх размеров дизайн-системы и сломанных карточек/форм в тёмной
теме. Поля на телефоне используют 16 px. Локальная прокрутка таблиц истории
сохраняется и доступна с клавиатуры. Различаются loading, empty и request
error; проверены retry, компактные ошибки дополнительных разделов,
сохранение карточек/ввода при фоновом сбое, успех настоящего сохранения,
ошибки сети/сервера и восстановление черновика. Фокус проверяется через
клавиатуру и computed outline, включая меню, Escape, summary и skip-link.

## Проверки

- typecheck, lint, production build, format:check, architecture:check — exit 0.
- Vitest: 150 тестов в 25 файлах прошли.
- Новая постоянная браузерная матрица final-ui-quality: 72 Chromium passed.
- Регрессии direction-form-ux, request-states, tracker-tools, landing,
  source-catalog: 50 Chromium passed, 2 skipped. Пропуски требуют
  E2E_SOURCE=1 и проверенного архива/DTO в живом API.
- PostCSS-проверка styles.css, tracker.css, ui.css: повторов свойства внутри
  одного правила нет. Каскад общих controls дополнительно проверен в браузере;
  необходимые responsive/theme overrides сохранены. Это не утверждение об
  отсутствии любых одинаковых селекторов во всём проекте.
- git diff --check — без ошибок whitespace.

Firefox пытался запуститься, но страницы падали с
`browserContext.newPage: Target crashed` до отображения интерфейса: проверка
не выполнена, совместимость Firefox не подтверждена. WebKit/Safari не запущен
(браузер не установлен). Физические телефоны, screen reader, полный WCAG-аудит,
живой backend/настоящие источники и deployment не проверялись. API-сценарии
проверены с явными тестовыми ответами, включая неуспешные запросы; production
код не подменяет ошибки успешными данными. Открытых UI-дефектов в проверенной
матрице не осталось; перечисленные ограничения сохраняются.
