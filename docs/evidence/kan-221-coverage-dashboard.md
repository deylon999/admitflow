# KAN-221: дашборд покрытия РФ и контроль свежести

Операторский экран `/app/coverage` и API `GET /api/v1/coverage/national`. Тот же отчёт без HTTP: `python -m app.national_coverage --output report.json` из `backend/`.

## Что показано

Один знаменатель на все слои: **785** головных организаций с действующей аккредитацией бакалавриата или специалитета по реестру Рособрнадзора на 10.11.2026 ([KAN-217](kan-217-national-denominator.md)). Порог проекта 60% виден на каждой полосе.

Слои считаются отдельно и не смешиваются:

| Слой | Что засчитывается |
| --- | --- |
| Опорный каталог | Запись MICCEDU однозначно сопоставлена с организацией из реестра. Записи только из реестра не засчитываются |
| Проверенные программы | У головного вуза есть хотя бы одна программа из проверенного профиля с официальным источником |
| Требования ЕГЭ | Требования из официального источника. Пока таких данных нет, слой честно показывает 0 |
| Конкурсные списки | Опубликован полный снимок хотя бы одного конкурса. Свежие и архивные считаются отдельно |

Филиалы не засчитываются как головные вузы. Программы филиалов выведены отдельной строкой «не засчитаны».

Также показаны:
- разбивка по годам кампании;
- пробелы (вузы без программ, записи без сопоставления, неоднозначные, только из реестра);
- состояние каждого источника, проблемные источники списком (ошибка, карантин, устарел);
- очередь обновления и worker;
- таблица по регионам.

## Воспроизводимость

Отчёт содержит SHA-256 файла реестра и каталога, а также контрольную сумму всех показателей без времени формирования. При одинаковых входных данных контрольная сумма одинакова, это проверено тестом. Кнопка «Скачать отчёт JSON» сохраняет ровно ответ API.

## Фактические значения

На стенде браузерных тестов (2 проверенные программы СГУ, источников нет):

| Слой | Покрыто | Доля | Порог 60% |
| --- | ---: | ---: | --- |
| Опорный каталог | 675 из 785 | 86,0% | достигнут |
| Проверенные программы | 1 из 785 | 0,1% | нет |
| Требования ЕГЭ | 0 из 785 | 0,0% | нет |
| Конкурсные списки | 0 из 785 | 0,0% | нет |

На рабочем стенде с 15 архивными группами пяти вузов значения программ и списков будут другими, их показывает тот же экран. Утверждений о покрытии программ, ЕГЭ или списков, которого нет в данных, экран не делает.

Снимки экрана: [1440 px](kan-221-coverage-1440.png), [390 px](kan-221-coverage-390.png). Горизонтальной прокрутки страницы нет; таблица регионов на телефоне прокручивается внутри себя.

## Проверки

- `backend/tests/test_national_coverage.py`: раздельные слои на одном знаменателе, филиалы, воспроизводимость и отсутствие персональных полей, совпадение CLI и API, видимость упавшего источника;
- `frontend/tests/catalog.spec.ts`: экран, пороги, регионы, выгрузка JSON, переход со страницы источников.

## Ограничения

- Отдельной роли оператора в продукте нет. Экран открыт как остальные агрегаты источников, без персональных данных.
- Слой требований ЕГЭ пуст, пока не появится официальный источник (KAN-219).
