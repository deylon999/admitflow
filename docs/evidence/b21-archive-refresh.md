# B21/T223 — согласованное перечитывание архивных фактов

Исправлена F04. На исходном3494ed6 карточка перечитывалась дважды,
открытая архивная история и лента изменений — только один раз. При том же
snapshotId прежними оставались также сценарий и история сценариев.

Кнопка обновления инвалидирует текущие карточки, ленту изменений и mutable
истории/сценарии сохранённых подписок. Закрытые cached истории становятся
устаревшими и перечитываются при открытии. Сохранённые scenario-detail
остаются неизменяемыми. Ошибка одной загрузки не удаляет датированные
прежние факты; есть явное предупреждение и повтор.

При смене снимка React может отменить старый запрос и запустить новый с
другим ключом. Кнопка учитывает оба через scoped useIsFetching, поэтому
не становится доступной до завершения нового чтения. Ошибки начатых
обновлений собираются после allSettled; прежние данные сохраняются.

**8 passed**,14.8s, без skips. Проверены новый/тот же снимок, закрытые
истории,503 одной истории с задержкой другой, восстановление повтором,
неизменные тексты и число чтений immutable comparison. Build, Prettier и
git diff --check прошли. Отдельный compiled preview5283/API8033,
