[SHA‑256 манифест](visual-baselines.sha256) покрывает 20 каталожных baseline,
145 оригинальных кадров v3 и общий исторический кадр лендинга. Все пути в
манифесте относительны к корню репозитория. Проверки обновляют только свои
временные snapshot-копии в процессе прогона.

`compare-main.mjs` строит эталон из выбранного Git-коммита и сравнивает его
с рабочим frontend в одном Chromium, воспроизводя одни и те же ответы
локального API. Входом служит исходный код, а PNG и метрики записываются в
`frontend/test-results/compare-main-*`. `npm run test:visual` использует
соседний исходный проект v3. Оба сравнения локальные. Стандартный
`npm test` запускает проверки UI auth/каталога и сохраняет новые скриншоты
без чтения исторических PNG при выключенном `QA_BASELINE_REF`.

## Хранение новых результатов

- Небольшие проверенные baseline хранятся в Git вместе с хешем, версией
  эталона и ссылкой на тест или команду сравнения.
- Обычные PNG, отчёты и логи пишутся в игнорируемый `test-results/` компонента.
  Массовые скриншоты CI хранятся в GitHub Actions Artifacts. Текущий workflow
  публикует их вместе с отчётами, срок хранения составляет 7 дней.
- Долгосрочные доказательства хранятся в разделе соответствующего этапа.
  Документ этапа фиксирует коммит, команду, окружение, результат, ограничения
  и ссылки на выбранные доказательства. Архивную запись стоит сохранить
  отдельно от временного Actions Artifact, если она понадобится после его
  удаления.
- Официальные файлы и большие инвентари ведутся по правилам источников.
  `docs/sources/national-inventory.json` и `admissions-inventory.json`
  используются исследовательскими скриптами. Паспорта, исходные хеши и
  условия хранения описаны в [правилах данных](../DATA_RULES.md)
  и [национальной инвентаризации](../sources/national-inventory.md).

## Повторный аудит

Из корня репозитория:

~~~text
python scripts/audit_evidence.py
python scripts/audit_evidence.py --ref a3f50786b664b7b165c2be939a6ad5c7fa858a62
~~~

Утилита читает дерево Git и по умолчанию проверяет `HEAD`. Отчёт включает
размеры blob, группы SHA‑256, отслеживаемые пути под `test-results/`,
известные входы тестов, хеши baseline и локальные ссылки на evidence из
Markdown/HTML. Совпадения и большие файлы выводятся для ручной проверки
потребителей. Утилита работает только на чтение.
