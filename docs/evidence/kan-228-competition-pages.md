# KAN-228: рабочие страницы конкурсных списков и конкурентов v3

## Маршруты

| Маршрут | Что показывает |
| --- | --- |
| `/app/competitions` | Конкурсы, у которых есть импортированный список (архив или автоматическое обновление) |
| `/app/competitions/{groupId}` | Список в официальном порядке: место, баллы, согласие, приоритет (если источник его публикует), участие |
| `/app/competitions/{groupId}/competitors` | Агрегаты снимка: согласия, отзывы, приоритет 1, распределение баллов; для подтвердившего запись гостя — кто выше него |
| `/app/watchlist/{subscriptionId}` | Сохранённое направление с удалением (раньше было на `/app/competitions/{id}`) |

Демонстрационный экран `/app/competitions/mtuci-se` с `?mode=demo` и `/app/competitions/mtuci-se/competitors` из инвентаря дизайна не изменены.

## API

- `GET /api/v1/competitions/{groupId}`: метаданные опубликованного снимка, источник, состояние, история до 20 снимков, предупреждения и место гостя (`myRank`).
- `GET /api/v1/competitions/{groupId}/rows`: строки с фильтрами `consent`, `participation`, `priority`, `rankFrom`, `order=official|official-desc`, `offset`, `limit` ≤ 50.
- `GET /api/v1/competitions/{groupId}/summary`: агрегаты.

## Правила

- **Порядок только официальный.** Он уже учитывает равные баллы и дополнительные основания конкретного конкурса, поэтому сортировки по баллам нет: она дала бы неверный порядок.
- **Приоритеты не выдумываются.** Если источник их не публикует, колонки нет и показано предупреждение.
- **Предупреждения:** архив, неполный список, неизвестное число мест, строки с неизвестным согласием, ошибка или карантин источника, устаревший источник, неподдержанные правила (не бюджет или не общий конкурс).
- **Приватность.** Коды поступающих, ключи и ссылки на исходные строки не отдаются, это проверено тестом. Frontend отвергает строку с любым лишним полем. Свою строку гость видит только после подтверждения записи в «Мои направления». Другой гость и запрос без сессии её не видят. Поддельная cookie не ломает чтение публичного списка.

## Проверки

- **`backend/tests/test_competitions.py`:**
  - официальный порядок, пагинация и переход к месту;
  - отсутствие идентификаторов;
  - фильтры совпадают с подсчётом в БД;
  - гистограмма без пропусков;
  - своя строка видна только владельцу.
- **`frontend/tests/api.spec.ts`:**
  - список, предупреждения, фильтры, страницы и переход к месту;
  - отказ отображать строку с идентификатором;
  - агрегаты «кто выше»;
  - каталог списков.
- **Ручная проверка на архиве СГУ** (573 строки): экраны 1440 и 390 px без горизонтальной прокрутки страницы. В репозиторий положен только снимок агрегатов: [конкуренты](kan-228-competitors-1440.png). Снимки строк не сохранены, потому что в фикстуре реальные баллы (см. находку 4 аудита).

## Ограничения

- Импортированы только архивные списки пяти вузов, свежих нет. Страницы готовы к живым снимкам, но на них не проверялись.
- Правила согласий для платных, целевых и квотных конкурсов не моделируются: для них показываются только факты списка.
