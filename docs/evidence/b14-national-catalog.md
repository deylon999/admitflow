## T191: проверяемый импорт

Каталог импортируется как версионированный read-only JSON artifact, без изменения пользовательских таблиц, подписок, существующих операторских названий и регистрации автоисточников. Это позволяет поставить полный опорный перечень в новой установке без миграции источников. Новые ID miccedu-N стабильны по внешнему идентификатору; явно сверенные 258/1715/243 сохраняют sgu-saratov/sgups-novosibirsk/guap-spb. Филиал не объединяется с головной организацией по домену.

`python -m app.national_catalog validate` проверил 1257 записей/521 филиал. Импорт из backend: `python -m app.national_catalog import --input app/data/national-catalog.json --output var/catalog-copy.json`. Полная валидация предшествует атомарной замене; уникальный temporary file позволяет безопасный повтор. Артефакт загружается один раз на процесс; обновление требует перезапуска приложения.
