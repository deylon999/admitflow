## Правило знаменателя

Головной вуз — юридическое лицо с уникальным ОГРН, у которого в реестре:

1. свидетельство в статусе «Действующее»;
2. есть действующее приложение;
3. в нём есть хотя бы одна не отменённая и не приостановленная программа бакалавриата или специалитета с кодом вида `NN.NN.NN`.

Филиалы имеют ОГРН головной организации, поэтому считаются один раз вместе с ней, а в данных остаётся только их число. Признакам `IsBranch` и `HeadEduOrgId` верить нельзя: у нескольких головных организаций после реорганизации они заполнены (например, ОГРН 1025401932753). Поэтому головная организация определяется по свидетельству, а филиал — по флагу приложения или названию «Филиал…».

Организации, зарегистрированные за рубежом (без российского ОГРН: межгосударственные университеты в Армении, Таджикистане, Белоруссии, Киргизии и Приднестровье), перечислены, но в знаменатель не входят: 5.

ФИО руководителей, телефоны, адреса и e-mail из реестра не читаются в выходной файл; это проверено тестом.

## Воспроизведение

1. Скачать ZIP со [страницы набора](https://isga.obrnadzor.gov.ru/accredreestr/opendata/), не меняя имя `data-YYYYMMDD-structure-20160713.zip`.
2. Из корня: `python scripts/build_accreditation_registry.py <путь к ZIP>`.
3. `backend/app/accreditation_registry.py` проверяет файл целиком при загрузке; несогласованный файл отклоняется, а не используется частично.

Проверки: `backend/tests/test_accreditation_registry.py` (согласованность, учёт каждой записи каталога, отказ на повреждённых данных, построение на синтетическом XML без персональных полей, однозначность сопоставления), `test_product_catalog.py`, `test_coverage.py`, `frontend/tests/catalog.spec.ts`.

## Ограничения

- Ведомственная принадлежность определена по названию. Это эвристика, она только помечает подмножество и из знаменателя ничего не исключает.
- Реестр отражает аккредитацию, а не факт приёма в текущую кампанию: организация может иметь аккредитацию и не объявить набор.
- Регион части записей указан в реестре нестандартно, например Азовский ГПУ отнесён к «за пределами РФ» при российском ОГРН. Такие записи считаются российскими по ОГРН.
- Набор обновляется ежедневно. Знаменатель фиксирован датой выгрузки и обновляется повторным запуском скрипта.
