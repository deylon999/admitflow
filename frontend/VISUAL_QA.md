# Visual QA — проверка нового UI

- **Масштаб:** браузер 100%; desktop 1440×900; тест 390×844. Не требуй 125% зума как костыль.
- **Лендинг:** сопоставление с `assets/reference-original.png`. Исходный макет 941px, поэтому в демо используется CSS zoom для desktop. При реальном внедрении можно заменить на fluid CSS.
- **Шапка:** компактные кнопки «Войти», «Оценить шансы», одинаковая линия высоты. Без огромных кнопок на 80px.
- **Прогноз:** мягкая тень самого элемента, не дополнительный серый прямоугольник. Текст 74% и 280–285 отчётливо виден; все значения условные.
- **Фигуры:** ring и lime accent не должны перекрывать формы, вылезать за радиус секции или вызывать скролл.
- **Карточки:** контентная плотность, без пустых 100px между полями и действиями. Применяются единые радиусы/отступы.
- **Внутренние страницы:** отдельный Header, Sidebar, MainContent и reusable компоненты. Навигация внутри сайта, не ссылки на Figma.
- **Адаптив:** 390px в любой странице не даёт горизонтальный скролл. Текст не обрезается.
- **Числа:** без фальшивой точности модели, все примеры помечены как «демо».
- **Модалки:** доступный заголовок, осмысленные кнопки, закрытие.

Скриншоты лежат в `screenshots/`. Если пользователь замечает несовпадение — сравнивать локальный рендер с оригиналом и исправлять визуальную геометрию, а не просто переименовывать классы.
