# AdmitFlow frontend v3 — исправления визуальных недочётов

## Что изменено

- Красные, синие и фиолетовые поверхности: согласованная контрастная палитра для заголовков, текста и дат; белый текст на тёмно-красном (`#d92d20`). Светлый оттенок красного сохранён для остальных брендовых элементов.
- Уведомление «5 дней назад» теперь читаемое: белый текст на красном фоне. На лаймовом фоне дата тёмная.
- Устранён глобальный конфликт `h2 { color: var(--ink) }`: заголовок «Экзамен легче ≠ поступить легче» заменён более понятным пояснением с белым текстом.
- Каталоги `/universities`, `/universities/mtuci`, `/programs`, `/programs/mtuci-se` и аналитика `/ege-analytics` используют одну оболочку `AppShell`, как остальные внутренние страницы. Сайдбар не пропадает, активный раздел подсвечивается.
- График ЕГЭ показывает распределение долей **в процентах**, подписи X/Y, легенду 2026/2027, отдельные данные при смене предмета и краткий вывод. Условные числа вынесены в `src/data/demo.ts` и складываются в 100% по каждому году/предмету. График подписан «Пример данных», чтобы не вводить в заблуждение.
- Убраны повторяющиеся `DemoNotice` и большие баннеры про концепт, повтор в футере, ненужный чекбокс в форме и дублирующие объявления.
- Карточки с направлениями слегка уплотнены по вертикали.

## Как посмотреть

Открой `preview/all-pages.html` — все 29 страниц, можно открывать без npm. Для интерактивного React: `npm install && npm run dev`.

## Проверки

- 29 страниц × 2 размера экрана (1440px и 390px) = 58 экранов; горизонтальных переполнений 0.
- 61 текстовый фрагмент внутри цветных карточек: 0 нарушений контраста WCAG AA (нормальный текст 4.5:1) в автоматической проверке. Результат: `screenshots/contrast-audit.json`.
- `node scripts/build-offline-preview.cjs` скомпилировал TSX и сгенерировал 29 страниц.
- Полная сборка Vite/npm не запускалась, поскольку в этой среде отсутствуют пакеты npm проекта.

**Важное ограничение:** интерфейс прототипа использует условные данные и ещё не подключён к реальной ML-модели или источникам вузов. Удаление повторяющихся предупреждений не меняет статус данных.
