# AdmitFlow — полный фронтенд-дизайн-кит

**Версия 2.0:** 29 самостоятельных маршрутов вместо одного лендинга, реальные редактируемые React/TypeScript-компоненты, общий дизайн, адаптивная верстка, офлайн-превью и скриншоты. Все числовые прогнозы и конкурсные списки **демонстрационные**: ML-модели и реального backend здесь нет.

## Быстрый просмотр без установки зависимостей

Откройте `preview/index.html`, затем переходите по ссылкам на остальные страницы. Навигация работает между офлайн HTML-файлами; это **статические снимки** тех же React-компонентов. Из них удобно переносить дизайн, но интерактивные состояния (поиск, фильтры, формы) работают только при запуске React.

Полный перечень ссылок: `preview/all-pages.html`.

**Масштаб:** проверено в Chromium при масштабе браузера **100%** и ширине **1440px**, а также в мобильном окне **390px**. Раньше лендинг имел узкий контейнер 856px; в v2 на больших дисплеях встроено масштабирование этого референса через CSS `zoom`, но остальные страницы сразу свёрстаны под нормальную ширину 1200px. Не требуется выставлять браузер на 125%.

## Запуск исходников

```bash
npm install
npm run dev
```

Откройте адрес Vite (обычно `http://localhost:5173/`). Для сборки:

```bash
npm run build
```

Здесь исходники преобразованы TypeScript, HTML-превью собраны и визуально проверены в Chromium. В окружении отсутствуют npm-зависимости React и Vite, поэтому **полный `npm run build` в этой среде не выполнен**; после установки зависимостей обязательно проверьте.

## Что работает в React

- SPA-переходы `History API`, браузерные «Назад/Вперёд»;
- Каталог вузов: поиск и фильтр города; каталог программ: поиск;
- Трекер: добавить/убрать направление, хранение в `localStorage`;
- Форма баллов ЕГЭ и сумма введенных баллов;
- Таблица конкурса: фильтрация и поиск по коду;
- Сравнение до четырёх направлений;
- Переключатель предмета в аналитике ЕГЭ;
- FAQ через нативные `<details>`;
- Демонстрационные модальные окна настроек и формы авторизации (серверные запросы отсутствуют).

## Передача в существующий AdmitFlow

**Не заменяйте свой репозиторий целиком.** Этот проект — дизайн-эталон. Пусть GPT Sol переносит UI в ваш существующий React/FSD поэкранно, сохраняя настоящий API, состояния, источники, парсеры, безопасность и бизнес-правила. См. `PROMPT_FOR_CODEX.md`.

## Ограничения

- Это большой проработанный **фронтенд-прототип**, но не готовый сервис с рабочими ML и подключениями вузов.
- Прогнозы 74%, 91%, 270–282 и т. д. — только визуальные примеры, их нельзя показывать пользователям как реальные шансы.
- Все варианты интерфейса адаптивные, но не представляют буквально бесконечное число состояний; покрыты маршруты из `SCREEN_INVENTORY.md`, дополнительные редкие UX-ветки Codex проектирует по реальной логике проекта.
- Pixel-perfect соответствие на главной — приближение к изображению-референсу. Без авторских исходников точную копию 1:1 гарантировать нельзя.
