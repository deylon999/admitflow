# Общие библиотеки

- `time`: строгая обработка ISO-времени и порядок opaque identifiers.
- `json`: JSON parser с отклонением неоднозначных/повторных ключей.
- `text`: операции над Unicode code points.
- `download`: браузерное скачивание JSON по переданному имени файла.

Библиотеки не знают про направления, источники, формулы, квоты или имена
экспортов AdmitFlow. Предметные правила и названия файлов принадлежат сущностям
и features. Внешние потребители используют index.ts каждой библиотеки.
