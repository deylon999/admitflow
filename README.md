# AdmitFlow

Помогает абитуриентам следить за положением в конкурсных списках вузов и сравнивать направления.

Сейчас доступны калькулятор места, сохранение направлений и история изменений. Данные вводятся вручную; автоматическое обновление списков в разработке.

**Стек:** React, TypeScript, Vite · Python, FastAPI, SQLAlchemy.

## Локальный запуск

Нужны Node.js 22.12+ и Python 3.12. Из корня репозитория:

```sh
cd frontend
npm ci
npm run dev
```

Интерфейс: http://127.0.0.1:5173. Для сохранения направлений нужен API — [инструкция запуска](docs/RUNBOOK.md#команды-приложения).

`frontend/` — интерфейс · `backend/` — API · `shared/` — общие тестовые данные · `docs/` — документация · `scripts/` — проверка плана.
