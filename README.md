# AdmitFlow

AdmitFlow помогает искать вузы и программы, читать подтверждённые требования к поступлению и отслеживать свою запись в доступных конкурсных списках. React и TypeScript отвечают за интерфейс, FastAPI и PostgreSQL — за API и данные.

- `/universities` и `/programs` показывают справочник вузов, публичные программы и происхождение данных. Штатный локальный импорт добавляет две проверенные архивные записи СГУ за 2026 год.
- `/app/competitions`, `/app/watchlist` и `/app/coverage` работают с опубликованными списками, гостевыми подписками и отдельными метриками покрытия. Списки импортируются отдельно.
- Регистрация и восстановление доступны при включённом `AUTH_ENABLED`. Прогноз открывается в деморежиме по `/app/forecast?mode=demo`.

## Локальный запуск

Из корня репозитория с запущенным Docker Engine и Compose v2:

```bash
python scripts/local_smoke.py
```

Откройте [AdmitFlow](http://localhost:8080) после `PASS`. Стек остаётся запущенным. Скрипт копирует текущую БД перед миграциями, импортирует публичный каталог и проверяет сохранность данных после пересоздания контейнеров. Результаты и приватная копия находятся в `test-results/local-start/`. Порт можно изменить через `WEB_PORT` в локальном `.env`. Для остановки с сохранением томов используйте `docker compose stop`.
